# NullPointerArena

## Description
NullPointerArena is a student project from CalPoly Humboldt that will be a code testing webapp. The purpose of the program is to allow for easy to create in house programming contests while also giving students and club members experience on a collaberative project.

## tech stack (subject to change)
- python
- FastAPI
- React
- PostgreSQL
- redis queue

# project requirements
## stage 1
- file upload
- test code
- pass/fail output

## stage 2
- login
- admin panel
- editable problem list

## stage 3
- saved submissions
- score calculator
- problem sets
